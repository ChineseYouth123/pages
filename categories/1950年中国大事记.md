# 1950年中国大事记

> 1950年是中华人民共和国成立后的第一个完整年份，也是新中国巩固政权、恢复经济、走向世界的关键一年。当年大事集中于：统一财经稳定物价、废除旧法统与《婚姻法》《土地改革法》颁布、解放海南岛与舟山群岛、出兵抗美援朝、镇压反革命等。以下按时间线整理。
>
> **注**：资料主要整理自《中国共产党大事记·1950年》（人民网）、全国政协文史资料《1950年大事记》、中国共产党新闻网"四史"学习资料及公开史料。

---

| 日期             | 事件                           | 类别    | 内容与意义                                                                                               |
| -------------- | ---------------------------- | ----- | --------------------------------------------------------------------------------------------------- |
| 1月             | 全国财政经济统一工作开始                 | 经济    | 为克服恶性通货膨胀，政务院着手统一全国财政收支、物资调度与现金管理，为全年物价稳定奠定基础。                                                      |
| 1月             | 政务院批准《关于全国税收实施要则》等方案         | 经济    | 统一税制，简化税种，建立新中国的税收制度。                                                                               |
| 1月             | 中苏谈判订立新约                     | 外交    | 毛泽东率代表团访苏，与苏联就签订新的中苏条约进行谈判。                                                                         |
| 2月14日          | 《中苏友好同盟互助条约》签订               | 外交    | 周恩来与苏联外长维辛斯基在莫斯科克里姆林宫签署，4月11日生效，有效期30年。条约取代1945年国民党政府与苏联签订的旧约，确立中苏同盟关系，为新中国提供安全保障与经济援助，体现"一边倒"外交方针。 |
| 3月3日           | 政务院通过《关于统一国家财政经济工作的决定》       | 经济    | 统一全国财经工作，平衡收支、稳定物价，至3月中旬全国物价趋于平稳，财政经济状况开始好转。                                                        |
| 4月13日          | 《中华人民共和国婚姻法》通过               | 法制    | 中央人民政府委员会第七次会议通过，5月1日公布施行。废除包办强迫、男尊女卑的封建婚姻制度，确立婚姻自由、一夫一妻、男女权利平等原则，是新中国第一部婚姻法律。                      |
| 4月16日—5月1日     | 海南岛战役                        | 军事    | 解放军第四野战军15兵团发动渡海登陆战役，4月23日解放海口，5月1日全岛解放，共歼敌3万余人。                                                    |
| 5月19日          | 舟山群岛解放                       | 军事    | 解放军解放舟山群岛，国民党军撤往台湾，东南沿海屏障进一步巩固。                                                                     |
| 6月6日—9日        | 中共七届三中全会召开                   | 政治    | 毛泽东作《为争取国家财政经济状况的基本好转而斗争》书面报告和《不要四面出击》讲话，提出"三年恢复"的任务与方针，为国民经济恢复制定纲领。                                |
| 6月14日—23日      | 全国政协一届二次会议                   | 政治    | 讨论并原则通过《土地改革法（草案）》，通过国徽图案。                                                                          |
| 6月25日          | 朝鲜战争爆发                       | 国际    | 朝鲜南北战争爆发，美国随即出兵干涉并封锁台湾海峡，新中国面临严峻外部考验。                                                               |
| 6月28日          | 中央人民政府委员会通过《中华人民共和国土地改革法》    | 法制    | 6月30日公布施行，废除封建土地所有制，实行农民土地所有制。此后全国新解放区大规模土地改革逐步展开，至1952年底大陆土改基本完成。                                  |
| 6月28日          | 周恩来发表声明谴责美国侵占台湾              | 外交    | 声明指出台湾是中国领土不可分割的一部分，谴责美国第七舰队侵入台湾海峡。                                                                 |
| 7月23日          | 政务院、最高人民法院联合发布《关于镇压反革命活动的指示》 | 政治    | 针对残留特务、土匪、恶霸等反革命分子的破坏活动，部署开展镇压反革命工作。                                                                |
| 8月下旬           | 政务院召开治淮会议                    | 经济/民生 | 决定根治淮河，此后毛泽东题词"一定要把淮河修好"，新中国第一项大规模水利建设启动。                                                           |
| 9月25日—30日      | 全国战斗英雄代表会议与全国工农兵劳动模范代表会议     | 政治    | 两个会议同时在北京举行，表彰战斗英雄与劳动模范，毛泽东出席并致词。                                                                   |
| 10月6日—24日      | 昌都战役                         | 军事    | 解放军进军西藏，解放昌都，迫使西藏地方政府接受和平谈判，为1951年西藏和平解放打开道路。                                                       |
| 10月8日          | 毛泽东发布《给中国人民志愿军的命令》           | 军事    | 中共中央根据朝鲜党和政府请求与国家安全需要，作出抗美援朝、保家卫国的战略决策。                                                             |
| 10月10日         | 中共中央发出《关于镇压反革命活动的指示》         | 政治    | 即"双十指示"，针对镇压反革命中"宽大无边"的偏向，要求坚决肃清反革命势力，镇压反革命运动在全国展开。                                                 |
| 10月19日         | 中国人民志愿军入朝作战                  | 军事    | 志愿军在司令员兼政治委员彭德怀率领下跨过鸭绿江，秘密开赴朝鲜前线。                                                                   |
| 10月25日—11月5日   | 抗美援朝第一次战役                    | 军事    | 志愿军在西线、东线发起突然进攻，歼敌1.5万余人，将"联合国军"从鸭绿江边赶回清川江以南，初步稳定战局。10月25日被定为中国人民志愿军出国作战纪念日。                        |
| 10月            | 抗美援朝运动在全国掀起                  | 政治    | 全国开展"抗美援朝、保家卫国"宣传运动，各界踊跃捐款捐物、参军参战。                                                                  |
| 11月4日          | 各民主党派联合发表抗美援朝宣言              | 政治    | 中国共产党与民革、民盟、民建、民进、农工党、致公党、九三学社、台盟等联合发出宣言，拥护抗美援朝。                                                    |
| 11月25日—12月24日  | 抗美援朝第二次战役                    | 军事    | 志愿军诱敌深入后发起反击，歼敌3.6万余人，12月6日收复平壤，将敌人赶回"三八线"附近，扭转朝鲜战局。                                                |
| 12月28日         | 政务院发布管制美国在华财产、冻结美国在华存款的命令    | 政治/经济 | 针对美国侵朝、侵占台湾及冻结中国在美资产的行动，接管或管制美国在华企业，冻结美国在华存款。                                                       |
| 12月31日—1951年1月 | 抗美援朝第三次战役                    | 军事    | 志愿军与朝鲜人民军突破"三八线"，1951年1月4日占领汉城（首尔），将战线推进至"三七线"附近。                                                   |

---

*注：本大事记按公历时间排序，部分月份未列日常性政务活动。史料主要参考《中国共产党大事记·1950年》（人民网资料中心）、全国政协《1950年大事记》、中国共产党新闻网等公开资料。*
