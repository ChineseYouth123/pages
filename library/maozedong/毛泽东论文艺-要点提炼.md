## 二、《在延安文艺座谈会上的讲话》——核心纲要

### 引言：五个基本问题

| 问题       | 要点                             |
| -------- | ------------------------------ |
| **立场**   | 站在无产阶级的和人民大众的立场；党员要站在党的立场；     |
| **态度**   | 歌颂人民、暴露敌人，对同盟者有联合有批评           |
| **工作对象** | 文艺作品为工农兵及其干部而作                 |
| **工作**   | **了解人熟悉人是第一位的工作**，思想感情与工农兵打成一片 |
| **学习**   | 学习马克思列宁主义和学习社会                 |

> **"最干净的还是工人农民，尽管他们手是黑的，脚上有牛屎，还是比资产阶级和小资产阶级知识分子都干净。"**

### 结论一：为什么人的问题——根本的问题，原则的问题

| 层次       | 内容                                                                     |
| -------- | ---------------------------------------------------------------------- |
| **服务对象** | **工人**（领导革命的阶级）、**农民**（最广大最坚决的同盟军）、**士兵**（武装的工人农民）、**城市小资产阶级**（革命的同盟者） |
| **批判倾向** | 小资产阶级立场——把自己的作品当作小资产阶级的自我表现                                            |
| **解决途径** | 在深入工农兵群众、深入实际斗争的过程中，**把立足点移过来**                                        |
| **根本判断** | **"为什么人的问题，是一个根本的问题，原则的问题。"**                                          |

> **"鲁迅曾说：'联合战线是以有共同目的为必要条件的……如果目的都在工农大众，那当然战线也就统一了。'"**

### 结论二：普及与提高

| 概念 | 内涵 |
|------|------|
| **源泉** | **人民生活中存在着文学艺术原料的矿藏，是最生动、最丰富、最基本的东西，是一切文学艺术取之不尽、用之不竭的唯一的源泉** |
| **源与流** | 过去的文艺作品不是源而是流；必须继承和借鉴，但不能替代自己的创造 |
| **普及** | **"雪中送炭"**——用工农兵自己所需要、所便于接受的东西向他们普及 |
| **提高** | **在普及基础上的提高**——沿着工农兵自己前进的方向去提高 |
| **关系** | **普及是人民的普及，提高是人民的提高**；普及为基础，提高为指导 |

> **"文艺作品中反映出来的生活却可以而且应该比普通的实际生活更高，更强烈，更有集中性，更典型，更理想，因此就更带普遍性。"**

> **"只有代表群众才能教育群众，只有做群众的学生才能做群众的先生。"**

> **"我们是无产阶级的革命的功利主义者，我们是以占全人口百分之九十以上的最广大群众的目前利益和将来利益的统一为出发点的。"**

### 结论三：党的文艺工作与统一战线

| 原则 | 要点 |
|------|------|
| **文艺与政治** | **文艺从属于政治**，是革命机器中的"齿轮和螺丝钉"；否定超阶级的艺术 |
| **政治与真实** | 文艺的政治性和真实性能够完全一致 |
| **统一战线三层次** | 抗日（最广）→ 民主（较窄）→ 艺术方法/作风（最窄） |
| **团结与斗争** | 只有团结而无斗争（右倾），或只有斗争而无团结（"左"倾），都是错误的 |

> **"在现在世界上，一切文化或文学艺术都是属于一定的阶级，属于一定的政治路线的。为艺术的艺术，超阶级的艺术，和政治并行或互相独立的艺术，实际上是不存在的。"**

### 结论四：文艺批评的标准

| 标准 | 内涵 |
|------|------|
| **政治标准（第一位）** | 一切利于抗日和团结、鼓励群众同心同德的，便都是好的 |
| **艺术标准（第二位）** | 艺术性较高的，是好的或较好的 |
| **动机与效果** | **辩证唯物主义的动机和效果的统一论者**——社会实践及其效果是检验主观愿望的标准 |
| **最终要求** | **政治和艺术的统一，内容和形式的统一，革命的政治内容和尽可能完美的艺术形式的统一** |

**批判六种错误观点：**

| 错误观点 | 毛泽东的批驳 |
|----------|-------------|
| **"人性论"** | 只有具体的人性，没有抽象的人性；在阶级社会里只有带着阶级性的人性 |
| **"人类之爱"** | 世上决没有无缘无故的爱，也没有无缘无故的恨；真正的人类之爱在全世界消灭了阶级之后 |
| **"写光明黑暗并重"** | 苏联以写光明为主；反动时期资产阶级把光明黑暗颠倒 |
| **"文艺的任务就在于暴露"** | 暴露的对象只能是敌人，对人民是教育和提高的问题 |
| **"还是杂文时代"** | 杂文形式不应简单地和鲁迅一样；可大声疾呼，不要隐晦曲折 |
| **"心是好的，表现不好"** | 效果问题就是立场问题；真正的好心必须顾及效果 |

> **"一切危害人民群众的黑暗势力必须暴露之，一切人民群众的革命斗争必须歌颂之，这就是革命文艺家的基本任务。"**

### 结论五：整风与思想改造

| 要点 | 内涵 |
|------|------|
| **思想入党** | 组织上入党不等于思想上入党；需要展开无产阶级对非无产阶级的思想斗争 |
| **两个时代** | 从亭子间到革命根据地，不仅是两种地区，而且是两个历史时代 |
| **鲁迅精神** | **"横眉冷对千夫指，俯首甘为孺子牛"**——做无产阶级和人民大众的"牛" |

> **"一定能够创造出许多为人民大众所热烈欢迎的优秀的作品，一定能够把革命根据地的文艺运动和全中国的文艺运动推进到一个光辉的新阶段。"**

## 三、各篇要点

### 1. 文化运动

| 要点 | 内容 |
|------|------|
| **核心论断** | 中国历来只有地主有文化，农民没有文化；地主的文化是从农民身上掠取的血汗造成的 |
| **实践** | 农民运动兴起后农民大办夜学，文化程度迅速提高 |
| **批判** | "洋学堂"脱离农村实际，不合作物需要 |

### 2. 神话与现实

| 要点 | 内容 |
|------|------|
| **神话的本质** | 无数复杂的现实矛盾的互相变化引起的一种幼稚的、想象的、主观幻想的变化 |
| **马克思论神话** | 神话是用想象以征服自然力；随着自然力被支配，神话消失 |
| **"永久的魅力"** | 最好的神话具有永久的魅力（马克思） |

### 3. 学习

| 要点 | 内容 |
|------|------|
| **三大学习任务** | **马克思主义理论**、**民族历史**、**当前运动的情况和趋势** |
| **理论联系实际** | 不把理论当教条，而当作行动的指南 |
| **马克思主义中国化** | **使马克思主义在中国具体化，带上中国的特性** |
| **中国作风中国气派** | **洋八股必须废止，空洞抽象的调头必须少唱，教条主义必须休息**，代之以新鲜活泼、为中国老百姓所喜闻乐见的中国作风和中国气派 |
| **对待历史** | 从孔夫子到孙中山，应当给以总结，承继这份珍贵遗产 |
| **学习态度** | **学习的敌人是自己的满足**；对自己"学而不厌"，对人家"诲人不倦" |

### 4. 五四运动

| 要点 | 内容 |
|------|------|
| **知识分子与工农** | **知识分子如果不和工农民众相结合，则将一事无成** |
| **最后分界** | 革命的或不革命的或反革命的知识分子的最后分界，在于是否愿意并且实行和工农民众相结合 |
| **五四意义** | 比辛亥革命进了一步，表现中国反帝反封建的资产阶级民主革命发展到新阶段 |

### 5. 新民主主义的文化

| 特征 | 内涵 |
|:----:|------|
| **民族的** | 反对帝国主义压迫，主张中华民族的尊严和独立；**吸收外国文化要经过消化，排泄糟粕，吸收精华**；反对"全盘西化" |
| **科学的** | **反对一切封建思想和迷信思想**，主张实事求是，主张客观真理，主张理论和实践一致 |
| **大众的** | **为全民族中百分之九十以上的工农劳苦民众服务**；革命文化是革命的有力武器 |

> **"鲁迅是中国文化革命的主将，他不但是伟大的文学家，而且是伟大的思想家和伟大的革命家。鲁迅的骨头是最硬的，他没有丝毫的奴颜和媚骨……鲁迅的方向，就是中华民族新文化的方向。"**

> **"民族的科学的大众的文化，就是人民大众反帝反封建的文化，就是新民主主义的文化，就是中华民族的新文化。"**

### 6. 改造我们的学习

| 要点 | 内容 |
|------|------|
| **三大缺点** | 不注重研究现状、不注重研究历史、不注重马克思列宁主义的应用 |
| **主观主义的表现** | 无实事求是之意，有哗众取宠之心；**墙上芦苇，头重脚轻根底浅；山间竹笋，嘴尖皮厚腹中空** |
| **实事求是** | **"实事"就是客观存在着的一切事物，"是"就是客观事物的内部联系即规律性，"求"就是我们去研究** |
| **有的放矢** | **"的"就是中国革命，"矢"就是马克思列宁主义** |
| **没有调查就没有发言权** | 共产党领导机关的基本任务，就在于**了解情况和掌握政策**两件大事 |

> **"这种反科学的反马克思列宁主义的主观主义的方法，是共产党的大敌，是工人阶级的大敌，是人民的大敌，是民族的大敌，是党性不纯的一种表现。"**

### 7. 反对党八股

| 罪状 | 核心 | 名言/比喻 |
|:----:|------|-----------|
| **一** | **空话连篇，言之无物** | "懒婆娘的裹脚，又长又臭" |

| **三** | **无的放矢，不看对象** | "射箭要看靶子，弹琴要看听众" |
| **四** | **语言无味，像个瘪三** | 要向人民群众学习语言 |
| **五** | **甲乙丙丁，开中药铺** | 只列现象不分析问题 |
| **六** | **不负责任，到处害人** | "下笔千言，离题万里" |
| **七** | **流毒全党，妨害革命** | — |
| **八** | **传播出去，祸国殃民** | — |

> **"共产党不靠吓人吃饭，而是靠马克思列宁主义的真理吃饭，靠实事求是吃饭，靠科学吃饭。"**

> **"到什么山上唱什么歌。""看菜吃饭，量体裁衣。"**

### 8. 文化工作中的统一战线

| 要点 | 内容 |
|------|------|
| **名言** | **"没有文化的军队是愚蠢的军队，而愚蠢的军队是不能战胜敌人的。"** |
| **群众脑子里的敌人** | 反对文盲、迷信和不卫生习惯，比反对日本帝国主义还要困难 |
| **统一战线两原则** | 第一是团结，第二是批评、教育和改造 |
| **群众路线** | **两条原则：一条是群众的实际上的需要，一条是群众的自愿** |

### 9. 关于百花齐放、百家争鸣

| 要点 | 内容 |
|------|------|
| **方针性质** | 促进艺术发展和科学进步、促进社会主义文化繁荣的方针 |
| **反对行政强制** | 利用行政力量强制推行一种风格、禁止另一种风格，有害于艺术和科学的发展 |
| **真理发展规律** | **正确的东西总是在同错误的东西作斗争的过程中发展起来的；真的善的美的东西总是在同假的恶的丑的东西相比较而存在，相斗争而发展的** |
| **马克思主义不怕批评** | 马克思主义是一种科学真理，它是不怕批评的 |
| **种牛痘的比喻** | 同错误思想作斗争好比种牛痘，增强免疫力；**在温室里培养出来的东西，不会有强大的生命力** |
| **六条政治标准** | 是否有利于：团结全国各族人民、社会主义改造和建设、人民民主专政、民主集中制、共产党的领导、社会主义的国际团结——**最重要的是社会主义道路和党的领导两条** |
| **警惕修正主义** | 修正主义比教条主义有更大的危险性 |

### 10. 同音乐工作者的谈话

| 要点 | 内容 |
|------|------|
| **民族形式** | **艺术要有民族形式和民族风格，独树一帜** |
| **反对全盘西化** | 以中国艺术为基础，吸收外国的东西进行自己的创造 |
| **标新立异** | 中国这样大的国家，应该"标新立异"，**但应为群众所欢迎** |
| **洋为中用** | **向古人学习是为了现在的活人，向外国人学习是为了今天的中国人** |
| **有机结合** | 中国的和外国的要有机地结合，**学外国织帽子的方法，要织中国的帽子** |
| **非驴非马** | 骡子就是非驴非马；应该在中国的基础上面，吸取外国的东西，有机地结合 |

### 11. 同文艺界代表的谈话

### 12. 对晋绥日报编辑人员的谈话
