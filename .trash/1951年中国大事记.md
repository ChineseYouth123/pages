# 1951年中国大事记

> 1951年新中国成立第三年：抗美援朝战争进入相持阶段，朝鲜停战谈判开始；《惩治反革命条例》《劳动保险条例》公布，镇压反革命运动深入；《十七条协议》签订，西藏和平解放；《毛泽东选集》第一卷出版；年底"三反"运动拉开序幕。以下按时间线整理。
>
> **注**：资料主要整理自《中国共产党大事记·1951年》（人民网）、全国政协文史资料《1951年大事记》、新华网/中青在线等公开史料。

---

| 日期 | 事件 | 类别 | 内容与意义 |
| --- | --- | --- | --- |
| 1月4日 | 志愿军占领汉城 | 军事 | 抗美援朝第三次战役中，志愿军第39军一部与朝鲜人民军并肩占领汉城，将战线推进至"三七线"附近，1月8日战役结束。 |
| 1月25日 | 抗美援朝第四次战役开始 | 军事 | "联合国军"发动反扑，志愿军采取"西顶东放"方针，至4月21日战役结束，歼敌7.8万余人。 |
| 2月1日 | 中苏签订军事贷款协定 | 外交 | 周恩来与苏联方面签订协定，苏联向中国提供12.35亿卢布贷款，用于购买抗美援朝所需军事装备与物资。 |
| 2月21日 | 《中华人民共和国惩治反革命条例》公布 | 法制 | 为镇压反革命运动提供法律依据，明确反革命罪与量刑标准，推动镇反运动在全国深入进行。 |
| 2月26日 | 政务院公布《中华人民共和国劳动保险条例》 | 民生 | 新中国第一部劳动保险法规，规定职工在年老、疾病、工伤、生育等情况下的保险待遇，惠及广大职工。 |
| 4月22日 | 抗美援朝第五次战役开始 | 军事 | 志愿军发起战役反击，至6月10日结束，双方战线稳定在"三八线"附近，为停战谈判创造条件。 |
| 4月26日 | 西藏和平谈判代表团抵达北京 | 政治 | 以阿沛·阿旺晋美为首席全权代表的西藏地方政府代表团抵京，与中央人民政府代表团（首席代表李维汉）举行谈判。 |
| 5月23日 | 《十七条协议》签订，西藏和平解放 | 政治 | 中央人民政府与西藏地方政府在北京中南海勤政殿签订《中央人民政府和西藏地方政府关于和平解放西藏办法的协议》，规定驱逐帝国主义势力出西藏、西藏实行民族区域自治，西藏宣告和平解放。 |
| 6月1日 | 抗美援朝总会号召捐献武器 | 政治 | 中国人民抗美援朝总会发出"捐献飞机大炮"号召，全国掀起爱国捐献运动，至年底捐献折合飞机3720余架。 |
| 6月23日 | 苏联代表提出停战谈判建议 | 国际 | 苏联驻联合国代表马立克提出交战双方谈判停火与休战的建议，中朝方面响应，朝鲜战争走向政治解决。 |
| 7月10日 | 朝鲜停战谈判开始 | 军事/外交 | 朝鲜停战谈判首次会议在开城举行（后移至板门店），谈判与打打谈谈交织进行。 |
| 8月18日—10月 | 粉碎美军"夏季攻势""秋季攻势" | 军事 | 志愿军依托坑道工事粉碎"联合国军"两次大规模攻势，同时开展反"绞杀战"，建成"钢铁运输线"。 |
| 8月17日 | 达赖喇嘛返回拉萨 | 政治 | 经中央代表张经武等劝导，十四世达赖喇嘛从亚东返回拉萨，接受《十七条协议》。 |
| 9月 | 第一次全国农业互助合作会议 | 经济 | 会议讨论并通过《关于农业生产互助合作的决议（草案）》，提出"积极领导、稳步前进"方针，引导农民走互助合作道路。 |
| 9月 | 知识分子思想改造运动开始 | 政治 | 以北京大学教师学习为发端，全国知识分子参加思想政治学习运动，至1952年基本结束。 |
| 10月12日 | 《毛泽东选集》第一卷出版 | 文化 | 收入毛泽东1925—1937年著作，全国掀起学习热潮。 |
| 10月23日—11月1日 | 全国政协一届三次会议 | 政治 | 毛泽东致开幕词，会议号召"增加生产、厉行节约，以支持中国人民志愿军"，并通过相应决议。 |
| 10月24日 | 达赖致电中央拥护《十七条协议》 | 政治 | 达赖喇嘛致电毛泽东表示拥护协议，10月26日毛泽东复电祝贺。 |
| 10月26日 | 人民解放军进驻拉萨 | 军事 | 进藏部队在张国华、谭冠三率领下举行入城式，拉萨各界两万余人欢迎，五星红旗在世界屋脊升起。 |
| 12月1日 | 中共中央发出"三反"指示 | 政治 | 中共中央作出《关于实行精兵简政、增产节约、反对贪污、反对浪费和反对官僚主义的决定》，"三反"运动在全国党政机关展开。 |
| 12月15日 | 《关于农业生产互助合作的决议（草案）》下发 | 经济 | 决议（草案）经中共中央印发试行，农业互助合作运动逐步展开。 |

*注：本大事记按公历时间排序。史料主要参考《中国共产党大事记·1951年》（人民网资料中心）、全国政协《1951年大事记》、新华社"西藏和平解放"系列报道等公开资料。参见《[1950年中国大事记](./1950年中国大事记)》。*
